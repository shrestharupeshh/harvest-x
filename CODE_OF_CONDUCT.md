# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas and evidence rather than people,
and keep discussion on engineering and research substance. Harassment or discriminatory
behaviour is not tolerated.

Report concerns privately to the repository owner through GitHub
(<https://github.com/shrestharupeshh>). Reports are handled confidentially.
